## 1. U(1)-invariant ingredients

Use the conventions of arXiv:1504.07357:

`delta N^i = N D^i alpha`,

`delta nu = alpha`,

`delta A = N partial_perp alpha = dot(alpha)-N^i D_i alpha`,

`delta N = delta g_ij = 0`.

Then

`Ntilde^i = N^i - N D^i nu`

is U(1)-invariant, as is

`sigma_U = A/N - partial_perp nu - (D nu)^2/2`.

For a U(1)-neutral scalar `Sigma`, define

`Theta_U = [dot Sigma - Ntilde^i D_i Sigma]/N`.

The operator

`C(state) D_i Theta_U D^i Theta_U`

is therefore allowed by the local U(1) symmetry. Executable project theorem: `rtk/route_b_u1_invariant_mixed_scalar_gate.py`.

## 2. Candidate action skeleton

The minimum branch to test is schematically

`S = S_U1-gravity[N,N^i,g_ij,A,nu] + S_DBI[U(1)-neutral Sigma] + S_mix`,

with

`S_mix = integral N sqrt(g) C(state) D_i Theta_U D^i Theta_U`.

`S_DBI` must reproduce the already frozen production functions `rho(a)`, `p(a)`, `c_a^2(a)` and `M_K(a)` with one fixed action/state-function map.

The mixed term vanishes on an exactly homogeneous FLRW background because `D_i Theta_U=0`, so the background can remain the production DBI background while the perturbation kinetic kernel changes.

## 3. Exact RTK coefficient gate

For a rolling scalar background with normal speed `q` and Goldstone normalization `delta Sigma=q pi`, the mixed operator produces both

`C q^2 (D_i dot pi)^2`

and a lapse-gradient contribution with the same invariant product `C q^2`.

The production identity is

`K_pi = 2 M_Pl^2 M_K^2`.

Therefore exact RTK matching requires

**`C q^2 = K_pi/(2 M_K^2) = M_Pl^2`.**

This product is invariant under a scalar field rescaling. A small rolling speed cannot by itself suppress the static lapse-gradient response.

Acceptance rule: the same fixed action must generate this product over the full production state branch without epoch-by-epoch fitting.

## 4. Gravity DOF gate

- 2 tensor gravity polarizations;

RTK acceptance requires a fresh combined constraint calculation after `S_DBI+S_mix` is added. It is not sufficient to add the literature gravity DOF count to the scalar DOF count by hand, because matter couplings can alter secondary constraints.

Any second propagating scalar below the EFT cutoff rejects the candidate.

## 5. Radiative-stability gate — early, not deferred

The `eta_1=eta_2=0` surface is exceptional in the Hamiltonian analysis and the associated operators are marginal. The literature argues they are expected to be generated radiatively.

Therefore a classical one-scalar result is insufficient.

Acceptance requires at least one of:

- an additional exact symmetry/selection rule forbidding the dangerous operators;
- a technically natural fixed point/renormalization argument;
- a demonstrated EFT hierarchy in which radiatively generated detuning remains below the allowed extra-mode/PPN threshold throughout the full observational validity range.

Absent such protection, the U(1) branch remains YELLOW even if the classical quadratic kernel matches RTK.
